# KT 一問一答 PWA

## 内容
- 公式問題を学習順に並べた全130問
- 新しい学習順番号 + 元番号を併記
- 公式解答を表示
- A 基礎用語 / B 理解重視 / C 暗記中心
- テーマ別・ランダム・△/×復習
- ○ / △ / × の進捗を端末内に保存
- 「PowerPointの関連解説を見る」から提供された `Kt用語集.pptx` の関連スライドを表示
- オフライン対応PWA

## iPhoneでホーム画面に追加する方法
PWAとしてインストールするには、HTTPSで配信する必要があります。GitHub Pages、Cloudflare Pages、Netlify等の静的ホスティングに、このフォルダの中身をそのまま配置してください。

1. 配信されたURLをiPhoneのSafariで開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選択

一度読み込めば、問題データとスライド画像はService Workerにキャッシュされ、オフラインでも利用できます。

## データの扱い
問題文は `KT用語集_学習順再編_問題版.pdf` の130項目を、文言を変更せずデータ化しています（PDF上の改行だけ連結）。解答は公式解答に準拠した `KT用語集_学習順再編_解答版.pdf` を使用しています。

PowerPoint内に直接対応する説明が見当たらない元問題番号は `source_manifest.json` に記録しています。その場合、アプリは「直接対応する解説スライドは確認できない」と表示します。
