# KT 一問一答 PWA v2

アクチュアリー試験「経済・投資理論」向けの一問一答PWAです。
公式130問は学習順に並べ、元番号を併記しています。関連するPowerPointスライドを画像としてアプリ内表示します。

## v2で追加した機能

1. 各問題の「疑問記入欄」
2. 「疑問一覧」ページ
3. 疑問の「未解決 / 解決済み」管理
4. 疑問一覧から「問題へ」「PowerPointを見る」へのリンク
5. 学習進捗・最終学習位置・疑問メモのJSONバックアップ書き出し

既存v1の学習進捗は、同じlocalStorageキーを利用するため引き継がれます。

## GitHub Pages上のv1から更新する方法

1. このフォルダの中身を既存の `kt-quiz` リポジトリ直下へ上書きコピーします。
2. GitHub Desktopで変更を確認します。
3. Summary例: `Update KT quiz to v2`
4. `Commit to main`
5. `Push origin`
6. GitHub Pagesの反映後、iPhoneで一度アプリを閉じて再度開きます。古い画面が残る場合はSafariでサイトを再読み込みしてからPWAを開き直してください。

Service Workerのキャッシュ名はv2へ更新済みです。

## 疑問メモの保存先

疑問メモと進捗は、この端末のブラウザ内（localStorage）に保存されます。ブラウザデータを削除すると消える可能性があるため、定期的に「進捗」→「バックアップを書き出す」を利用してください。

バックアップはJSON形式です。iPhoneでは共有シートが開く場合、「ファイルに保存」等を選べます。
