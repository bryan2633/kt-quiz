# KT 一問一答 PWA v4

アクチュアリー試験KKT向けの一問一答PWAです。公式130問の問題・解答データとPowerPoint関連解説を維持し、v4では学習の再開と未消化復習を追加しています。

## v4で追加した機能

### 1. テーマ別に「続きから」再開
「テーマから始める」でミクロ、マクロ、貨幣金融などを選んだ場合、途中でホームへ戻ったりアプリを閉じたりしても、そのテーマ・難易度（A/B/C）の最後の位置を端末内に保存します。次回同じテーマを選ぶと、その位置から再開します。最後まで終えたテーマの再開位置はクリアされます。

### 2. 間違えた問題を未消化の復習キューに保持
「× できなかった」を押した問題は、単なる最新ステータスではなく復習キューに保存されます。期日を過ぎても、成功するまで消えません。

復習間隔は次の3段階です。

- ×を付けた翌日：1回目の確認
- 1回目を○で通過した翌日：2回目の確認
- 2回目を○で通過した5日後：1週間チェック
- 1週間チェックを○で通過：消化完了、復習キューから削除

期日に△を付けた場合は段階を進めません。期日に再び×を付けた場合は未消化のまま残り、復習チェーンを最初からやり直します。期日を逃しても問題は消えず、「未消化の復習」に残ります。

v2から更新した場合、現在の進捗で「×」になっている問題は自動的に復習キューへ移行します。過去に×を付けた後すでに○へ上書きされた履歴は、v2の保存形式には履歴が残っていないため遡及復元できません。

## GitHub Pagesの更新
更新用ZIPの中身を既存の `kt-quiz` フォルダへ上書きコピーし、GitHub Desktopで

1. Commit to main
2. Push origin

を実行してください。`assets/` はv2のものをそのまま使えます。Service Workerのキャッシュ名をv4へ変更しているため、公開後はiPhoneのPWAを一度完全に閉じ、再起動してください。古い画面が残る場合はSafariでGitHub Pagesを開いて再読み込みしてからPWAを開いてください。


## v4 追加仕様
- 進捗画面を円グラフ中心の表示へ変更。全体・各テーマについて「できた／微妙／できなかった／未学習」の構成を円グラフで確認できます。
- 件数は円グラフ横のコンパクトな4項目サマリーとして表示し、一目で確認できるようにしています。
- 全体進捗は他のテーマより大きい円グラフで最上部に表示します。
